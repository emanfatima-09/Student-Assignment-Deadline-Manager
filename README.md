# Student Assignment & Deadline Manager

## Project Description
Student Assignment & Deadline Manager is a simple web-based application developed to help students organize their assignments and keep track of deadlines.

## Features
- Add new assignments with title, subject, and due date.
- View all saved assignments.
- Delete assignments.
- Mark assignments as completed or pending.
- Filter assignments by status.
- Sort assignments by due date.
- View assignment progress (total, completed, and pending).
- Track deadlines with statuses such as Upcoming, Due Today, Overdue, and Completed.
- Store assignments in an SQLite database.

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- Git and GitHub

## How to Run the Project

1. Clone or download the project.
2. Open the project folder in VS Code.
3. Create and activate a virtual environment.
4. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

5. Run the application:

   ```bash
   python main.py
   ```

6. Open this address in your browser:

   `http://127.0.0.1:5000`

## Project Purpose
The purpose of this project is to provide students with a simple and organized way to manage coursework, monitor assignment progress, and keep track of important deadlines.
